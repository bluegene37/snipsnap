# Security & Privacy Policy

## Privacy Architecture

**snipsnap** is built on an **offline-first, zero-cloud-telemetry** model:

- **Local Processing**: Screenshots, images, annotations, and OCR operations are executed completely locally on your hardware.
- **Local SQLite / Drift Storage**: Captures and metadata are stored exclusively inside your local user data directory.
- **No Remote Telemetry**: No user data, screenshots, or extracted text are uploaded to any external server or third-party service.

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive privacy defect in snipsnap, please responsibly disclose it to the maintainers:

1. **Email**: Send a report directly to `security@genexis.dev` (or open a private security advisory on GitHub).
2. **Details**: Include steps to reproduce, affected platform(s), and potential impact.
3. **Response Time**: Maintainers will review and acknowledge your report within 48 hours and coordinate a security release.
